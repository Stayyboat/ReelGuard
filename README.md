# ReelGuard

Android companion app designed to reduce Instagram Reels scrolling.

The Android source project is included in `ReelGuard-project-download.zip`. See `BUILD-APK-ON-GITHUB.md` for build instructions.

## Current scope
The initial Android implementation uses an Accessibility Service to detect the Instagram Reels destination and show a blocking screen. Behaviour varies across Instagram versions and must be tested on-device. DM Reel swipe prevention and reliable filtering of suggested feed content are not claimed as complete.
